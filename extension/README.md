# Attune Chrome extension (MV3 prototype)

**Status: prototype / not submitted to the Chrome Web Store.**

## Interaction
- Floating **mascot** (not a text button): pick calm / a bit heavy / overloaded.
- **Default ON:** mascot click immediately prepares a load instruction for the **next** message you send (no confirm dialog). It never auto-sends.
- Empty composer: optionally fills a short “rewrite shorter” request **plus** the load note; you still press send.
- A chip shows “Load note ready” with **Undo**.
- Toggle in the popup: “Mascot click = apply immediately”.

## Permissions
`storage`, `activeTab`, host_permissions for chatgpt.com / claude.ai / gemini.google.com only.
